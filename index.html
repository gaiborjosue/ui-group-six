Car Maintenance & Info Webpage

1. Group Name: Car Maintenance & Info Webpage
Group Members: Tyler Nguyen, Daniel Gross, Edward Gaibor

2. Problem: To consolidate all the information needed to maintain personal vehicles while providing additional insights that allow users to make informed decisions about their car.

Users will be able to enter their vehicle information (Year, Make, Model, and Mileage), and the correct service intervals for fluid changes, tire rotations, and other vehicle maintenance tasks will be provided. Users will also be able to see an estimated value of their car based on the information entered.

For an improved user experience, the website will ideally feature an interactive 3D model of a car rendered directly on the page. Users will be able to navigate and click on specific parts of the vehicle (e.g., engine, tires, brakes, battery) to view maintenance details, service intervals, and related information for that specific component. This will make the interface more intuitive, visual, and engaging.

Potential Obstacles: Accessing accurate vehicle maintenance data and real-time car valuation based on user input may be challenging. We will need to find reliable data sources for each vehicle. Another obstacle is designing and implementing a visually appealing and practical way for users to interact with their vehicle data, especially if incorporating a 3D interactive model.

Instructions to Run the Prototype

The prototype is hosted through GitHub Pages and can be opened directly in a web browser using the link above. No installation, account setup, or build step is required.

To run it locally from the repository, open step5/index.html in a browser such as Chrome, Edge, Firefox, or Safari. The prototype uses static HTML, CSS, JavaScript, and local mocked data.

AI Use Disclosure

Tools: We used OpenAI Codex/ChatGPT as a design and coding assistant while building the Step 5 prototype in HTML, CSS, and JavaScript.

Process: Our sketches, task analysis, and paper-prototype testing guided the direction of the interface. AI helped us move faster from those ideas into a working browser prototype by suggesting layout structure, CSS styling, interaction code, mocked vehicle data, and small pieces of interface text. We used those suggestions as starting material rather than final decisions.

Human Agency: The team made the main design choices, including the car-maintenance workflow, the use of a simple static prototype, the dashboard organization, the diagnosis and maintenance flows, and the final visual direction. We revised the AI-assisted output to better match our own paper prototype, removed elements that felt too artificial or unnecessary, adjusted contrast and spacing, and reshaped the home screen so it felt more like our intended product instead of a generic generated mockup.
